# Analysis Results

Combined Substation + IEEE 13-Bus Feeder Protection Coordination Study
Generated by: run_all.py
Load data source: EIA WACM (Western Area Power Administration — Rocky Mountain Region)

## Phase 4: Combined System Validation

### Key observations vs standalone IEEE 13-bus benchmark:
- Bus 650: dropped from 1.0 pu (idealized) to 0.955–0.973 pu (real source)
- SubstationBus (13.8kV): 0.977–0.986 pu under full feeder load
- All buses within ANSI C84.1 Range A limits (0.95–1.05 pu)
- Voltage drop through bridging transformer accounts for the difference
  between standalone and combined model — confirms finite source impedance
  has a measurable effect on feeder voltage profile
- Combined model converges in one shot with no manual intervention

## Phase 5: 24-Hour Load Flow Results

- All buses within ANSI C84.1 Range A (0.95–1.05 pu) across all 24 hours
- Load shape sourced from EIA WACM real hourly demand data
- Voltage regulators between Bus 650 and Bus 632 functioning correctly,
  maintaining Bus 632 above 1.0 pu throughout the day
- Known data artifact at Hour 22: EIA WACM published value drops to
  0.7468 of peak (below 10% median threshold detection), causing an
  artificial voltage spike visible in the profile. This is a known
  edge-of-window data quality issue in the WACM dataset, not a system
  fault. Future improvement: widen the outlier detection threshold or
  fetch additional hours to better detect this artifact.
- Voltage profile plot: results/voltage_profile_24hr.png
